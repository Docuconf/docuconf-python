## 0.1.0

First version: typed configuration contracts for
[pydantic-settings](https://github.com/pydantic/pydantic-settings), implementing spec `v1alpha1`.

### Features

* Declarations from `BaseSettings` classes: descriptions, constraints, enums and secrets from pydantic, plus secret
  markers, URL schemes, CSV lists and file inputs.
* Export to `contract.cue` (`to_contract` and the `docuconf export` CLI), including `itemMin`/`itemMax` on int
  lists.
* Boot validation of variables and file inputs (TLS key pairs, CA bundles, keystores, config files) that reports
  every problem at once with stable error codes, with reload watching.
* Config-file overlays through pydantic-settings' file sources, injector reference checks, contract-first mode and
  the shared conformance runner.
* The `orders` example app.
